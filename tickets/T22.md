# T22 — Android native: VpnService DNS filter (Differentiator 1, Layer 1)

## Context
Spec §4, Layer 1: "Local `VpnService` intercepts DNS; queries checked against continuously
updated blocklists: adult domains, ad networks, adult ad networks, trackers, DoH/DoT bypass
endpoints. Blocks ~90–95% of ad/adult delivery at the network edge. Also force-routes
SafeSearch CNAMEs." KPI: "<10ms added latency per query, <3%/day battery." Blocklist sourcing
(LEDGER.md decision): free curated open lists — **StevenBlack, OISD, HaGeZi**, merged, not a
paid commercial feed.

**Environment reality (state this plainly in the report, do not hide it):** this repo has no
Java runtime, so Gradle/Kotlin compilation **cannot be verified here**. Write the real,
complete Kotlin implementation anyway — do not stub it out or leave TODOs — and add exact
setup steps to `SETUP.md` (`## Java / Android SDK`) so a human can build/run it later:
1. Install a JDK (e.g. `brew install --cask temurin` — Java 17 LTS is the current standard for
   modern Android Gradle Plugin).
2. Install Android SDK platform-tools + a platform + build-tools via `sdkmanager` (SDK dir
   already exists at `~/Library/Android/sdk` per this project's LEDGER.md) or via Android
   Studio's SDK Manager.
3. `cd app/android && ./gradlew assembleDebug` to build; `adb install` + a device/emulator to
   run.
Do not attempt to install a JDK yourself in this ticket — that's a system-wide tool install
left to the human per the project's scope decision.

Reuses `ContentFilterPolicy` (T02/T15) — the VPN's DNS filter reads
`contentFilter.categories`, `customBlockDomains`, `customAllowDomains`,
`safeSearchEnforced` from the child's active `Policy` (synced from T08, cached locally for
offline-first enforcement per spec §7).

## Requirements
In `app/android/app/src/main/kotlin/com/guardian/vpn/` (create the native module source tree
even if `app/android/` itself is a placeholder per T11's fallback path — if T11 used the
fallback, create the full directory structure here for real, it just won't be buildable until
the human runs `react-native init`'s platform template or otherwise sets up the Gradle project;
note this dependency explicitly if hit):

1. `GuardianVpnService.kt` — extends `android.net.VpnService`; establishes a local TUN
   interface, packet loop parses outgoing UDP/TCP port-53 (and DoH/DoT connection attempts —
   see bypass-prevention below) DNS queries, checks the queried domain against the loaded
   blocklist + policy categories, and either forwards to a real upstream resolver or returns a
   blocked/NXDOMAIN response. Force-rewrite SafeSearch-relevant domains (e.g.
   `www.google.com` → CNAME `forcesafesearch.google.com`, `www.bing.com` →
   `strict.bing.com`, DuckDuckGo safe param) when `safeSearchEnforced` is true, and YouTube to
   its restricted-mode-forcing host when `youtubeRestrictedMode` is true.
2. `BlocklistLoader.kt` — downloads/merges StevenBlack + OISD + HaGeZi list URLs (define the
   3 canonical raw-list URLs as constants with a comment citing each project), normalizes to a
   single domain-to-category mapping, persists to local storage (Room or a flat file — pick
   one, document choice), refreshed on a daily WorkManager job (`BlocklistRefreshWorker.kt`).
   Category-to-spec mapping: at minimum, tag entries as `adult`/`pornography`,
   `advertisements`/`adult_ad_networks`, `trackers` (matching T15's `CONTENT_CATEGORIES` ids).
3. `BypassPrevention.kt` — Layer 4 (spec §4): detect known VPN/proxy apps installed
   (PackageManager query against a small known-list constant), detect private-DNS override
   (`Settings.Global.PRIVATE_DNS_MODE`), maintain a blocklist of public DoH resolver IPs/hosts
   to also intercept at the TUN layer (so a bypass attempt via hardcoded DoH IP is still
   caught), and emit a `service_disabled`-shaped tamper `DeviceEvent` (T02 type) if the VPN
   service is stopped/disabled outside of parent action.
4. `VpnModule.kt` — the React Native native module bridge (`ReactContextBaseJavaModule`)
   exposing `startVpn()`, `stopVpn()`, `isActive()`, `refreshBlocklist()` to JS, plus emitting
   RN events for blocked-attempt (`block_attempt` `DeviceEvent`) and tamper signals.
5. `AndroidManifest.xml` additions: `<service>` entry for `GuardianVpnService` with
   `android.permission.BIND_VPN_SERVICE`, plus the `POST_NOTIFICATIONS`/foreground-service
   declarations this needs. Also add the Play Store disclosure string this triggers (link
   forward to T28, don't duplicate the compliance copy here — just leave a `// see T28
   compliance doc` comment marker at the manifest entry).
6. Where possible without a JVM, write a **pure-Kotlin-independent** unit-testable slice: the
   category-matching and SafeSearch-CNAME-rewrite logic should be expressible as a small pure
   function (`resolveDnsAction(domain, policy): DnsAction`) — port an equivalent version of
   this exact decision logic into `packages/domain/src/vpn/dnsDecision.ts` (TypeScript) with
   full Jest unit tests, explicitly as **the verifiable spec of the Kotlin logic's intended
   behavior** (the Kotlin file must implement the same decision table; note in both files'
   comments that they must be kept in sync, since this environment can verify the TS version
   but not the Kotlin one).
