# T12 — Parent dashboard: family/device list & instant pause

## Context
Spec §3.1: "Instant pause: parent locks all family devices with one tap." This is the parent
app's home screen after login — lists children/devices and surfaces the single most-used
control (instant pause) prominently, per the spec's emphasis on it as a headline feature.

Reuses `Family`, `Child`, `Device`, `Subscription` (T02) and calls T08's
`POST /policy-sync/instant-pause`.

## Requirements
In `app/src/parent/dashboard/` (screen registered on `ParentNavigator` per T11's append
pattern):

1. `DashboardScreen.tsx` — fetches the signed-in parent's `Family`, its `Child` list, each
   child's `Device` list (via `supabaseClient`), and current `Subscription.tier`. Renders:
   - A per-child card: name, device count vs `TIER_DEVICE_LIMIT[tier]` (import from
     `@guardian/domain`'s `tiers/features.ts`, T06), a "remaining time today" placeholder (real
     value wired in T14/T21, this ticket can show a loading/em-dash placeholder if the buckets
     query isn't wired here — do not fake a number).
   - A single, prominent **"Pause All Devices"** button that calls the instant-pause endpoint,
     with a confirmation dialog (this is a household-wide lock, must not fire on a stray tap).
2. `useFamily.ts`, `useInstantPause.ts` hooks wrapping the Supabase calls, with loading/error
   states (errors surfaced to the user, never swallowed per repo standards).
3. Tests (`@testing-library/react-native`): dashboard renders one card per child; pause button
   requires confirmation before calling the endpoint; device-count-vs-limit display matches
   `TIER_DEVICE_LIMIT`.

## Out of scope
- Editing policies (T13/T14/T15/T16) — this screen is read/overview + instant pause only.
- Real device-count enforcement UI (blocking add-device past the limit) — T20 (tier/paywall).
