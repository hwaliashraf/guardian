# T01 — Monorepo scaffold & tooling

## Context
First ticket of the Guardian parental-control app build (see `../project_spec_parental_app.md`
for full product spec; read `../LEDGER.md` for Phase-0 decisions before starting — in
particular: Supabase backend, npm workspaces, no bundled browser). This ticket only creates
the repo skeleton and tooling; no product logic yet.

## Requirements
Create, inside `projects/parental-app/` (the project root — do NOT touch anything outside it):

1. Root `package.json` using **npm workspaces** with workspaces: `["packages/*", "app"]`.
   Include root scripts: `lint`, `typecheck`, `test` (each fans out to workspaces via
   `npm run <script> --workspaces --if-present`).
2. Root `tsconfig.base.json`: `strict: true`, `target: ES2020`, `moduleResolution: bundler`,
   `esModuleInterop: true`. Each workspace's own `tsconfig.json` will `extend` this.
3. ESLint (flat config, `eslint.config.mjs`) + Prettier at the root, applying to all workspaces.
   Use `@typescript-eslint` recommended rules.
4. Jest configured at the root (`jest.config.js`) as a multi-project config that picks up
   `packages/*/src/**/*.test.ts` — no workspace exists yet, so it's fine for the initial run
   to report "no tests found"; just prove `npx jest --listTests` doesn't error.
5. Create empty directories with a `.gitkeep`: `packages/domain/src`, `packages/backend`,
   `app`.
6. Create `SETUP.md` at the project root with this exact skeleton (later tickets append to
   it — do not remove the placeholder headers):
   ```
   # Guardian — Environment Setup

   This file lists exact steps to finish setting up anything this build could not fully
   verify in its original build environment. Filled in incrementally per ticket.

   ## Node / npm
   (done — see below)

   ## Java / Android SDK (for native Android modules + Gradle builds)
   TBD

   ## Android device/emulator (for on-device verification)
   TBD

   ## Docker (for local Supabase dev)
   TBD

   ## Supabase CLI / project
   TBD

   ## Apple Developer account & FamilyControls entitlement (for iOS native modules)
   TBD

   ## Xcode / CocoaPods (for iOS builds)
   TBD
   ```
   Under "Node / npm" fill in the actual verified versions (run `node -v`, `npm -v`).
7. `.editorconfig` at root (2-space indent, LF, UTF-8, trim trailing whitespace).

## Out of scope
- No React Native app init yet (T11).
- No Supabase project files yet (T07).
- No actual domain logic yet (T02+).

## Done when
- [ ] `npm install` succeeds at the project root with no errors.
- [ ] `npx eslint . --ext .ts,.tsx` runs (may report 0 files linted — must not error).
- [ ] `npx jest --listTests` runs without error.
- [ ] `npx tsc -p tsconfig.base.json --noEmit` runs without error (even with no source files).
- [ ] `SETUP.md` exists with the skeleton above and Node/npm versions filled in.
- [ ] Evidence in the report: command output for each of the above.
